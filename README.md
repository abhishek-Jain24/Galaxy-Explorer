# 🌌 Galaxy Explorer

An interactive app for generating, customizing, and exploring
galaxy visualizations using Python and Streamlit.

> A procedural visualization, not a real astronomical simulation.

## Technologies

Python · Streamlit · NumPy · Matplotlib · Plotly


### Install dependencies

```bash
pip install -r requirements.txt
```

### Start the app

```bash
streamlit run app.py
```

## Development Sequence

1. Set up the app title, icon, and layout.
2. Add sidebar controls for stars, arms, twist, and spread.
3. Generate random star positions.
4. Implement spiral logic and coordinate conversion.
5. Draw and display the galaxy.
6. Add seed control and a new-galaxy button.
7. Add colors, glow, core, and background stars.
8. Add elliptical and irregular galaxy styles.
9. Add zoom, rotation, and star details.
10. Add JSON configuration save/load.
11. Add PNG download.
12. Add animation controls.
13. Add learning mode and formula explanations.
